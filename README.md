# LED-matrix-display

I've always enjoyed making electronics projects, especially ones involving LEDs/visual effects. After watching videos from Great Scott!, I became interested in building my own LED matrix display. Many of the projects I saw used custom PCBs and advanced programming, which felt intimidating for someone who has never worked with LED matrices. But I still wanted to create something similar, so I started looking for a simpler approach. That's when I found a pre-made 8×8 WS2812 LED matrix, which looked promising. Then I built a case around it and added an ESP32. For firmware, I found an easy-to-use open-source program called WLED.
